# Каталог сотрудников компании — OBLIVIONE RAGE

Веб-приложение для автоматизации учёта персонала, быстрого поиска контактных данных и управления базой сотрудников компании. Проект разработан в рамках учебной практики студентами АУГСГИП.

Приложение спроектировано как современное SPA (Single Page Application) с клиент-серверной архитектурой:
* **Frontend:** Vue 3 (Composition API, `<script setup>`), CSS3 с поддержкой адаптивных дизайн-систем и тем оформления (Light/Dark).
* **Backend:** Node.js, Express.js.
* **База данных:** SQLite (реляционная локальная БД).


## 👥 Распределение ролей в команде (5 человек)

В соответствии с планом разработки (Раздел 7 ТЗ) задачи были разделены следующим образом:
1.  **Frontend-разработчик (Компоненты и логика):** Реализация реактивного интерфейса на Vue 3, модальных окон, клиентской фильтрации, дебаунса поисковых запросов, логики переключения тем.
2.  **Frontend-разработчик (Вёрстка и UI/UX):** Адаптивная кроссбраузерная вёрстка, интеграция дизайн-системы, стилизация таблиц, компактных горизонтальных карточек сотрудников и элементов управления.
3.  **Backend-разработчик (API):** Создание сервера на Express.js, проектирование REST API маршрутов, реализация серверного поиска, пагинации, фильтрации и генерации CSV-файлов.
4.  **Backend-разработчик (БД и Безопасность):** Проектирование схемы SQLite, интеграция ORM/драйвера БД, реализация системы аутентификации для HR-отдела и защиты административных маршрутов.
5.  **QA / DevOps / Документовед:** Ручное и автоматизированное тестирование бизнес-логики, оптимизация производительности, деплой проекта на хостинг, составление финального отчета и технической документации.


## ⚙️ Функционал приложения

### 🌐 Публичная часть (Для всех сотрудников)
* **Интуитивный каталог:** Отображение персонала в виде компактных горизонтальных карточек (адаптированных под светлую и тёмную тему).
* **Умный поиск:** Живой поиск по ФИО, должности или отделу с механизмом *Debounce* (300 мс) для снижения нагрузки на сервер.
* **Фильтрация:** Быстрый отбор по департаментам компании через кастомные выпадающие списки.
* **Детальный просмотр:** Модальное окно с подробным досье сотрудника (рабочий Email, внутренний телефон, дата приёма на работу, биография/обязанности).

### 🔒 Административная часть (Для HR-отдела)
* **Авторизация:** Защищенный вход. При попытке регистрации выводится корпоративное уведомление о приватности системы.
* **Управление (CRUD):** Возможность добавления, детального редактирования и удаления (при увольнении) сотрудников.
* **Менеджмент аватаров:** Загрузка индивидуальных изображений или полная очистка/сброс фото до системной заглушки по кнопке.
* **Экспорт данных:** Выгрузка текущего отфильтрованного списка сотрудников в структурированный формат `CSV` (совместимый с Excel).


## 🗄️ Структура базы данных (SQLite)

База данных состоит из следующих реляционных таблиц:
* `users` — учётные записи HR-специалистов для доступа к панели управления (id, username, password).
* `departments` — справочник отделов компании (id, name).
* `employees` — данные сотрудников со связью `FOREIGN KEY (department_id) REFERENCES departments(id)` (id, name, position, department_id, salary, email, phone, hire_date, bio, photo_url).


## 🚀 Инструкция по локальному развертыванию

### Требования
* Установленный [Node.js](https://nodejs.org/) версии 16.x или выше.

### Шаг 1. Клонирование репозитория
Клонирование репозитория:

Bash
git clone https://github.com/amina33999/naviwal.git
cd naviwal
### Шаг 2. Установка зависимостей:

Bash
npm install
### Шаг 3. Запуск сервера (бэкенд):

Bash
node server.js
### Шаг 4. Запуск клиента (фронтенд):
В новом окне терминала:

Bash
npm run dev
